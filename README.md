# AL CLI (Agent Ledger)

**AL CLI**는 다양한 클라이언트 기능을 일관된 인터페이스로 제공하는 통합 경량 커맨드라인 도구(CLI)입니다. 여러 도메인의 기능을 단일 도구로 통합하여, 명령어 구조와 설정 방식을 통일된 경험으로 제공합니다. 증권사 API 연동을 통한 금융/주식 기능은 그 중 하나의 구현 사례입니다.

## 🚀 주요 기능

- **통합 CLI 인터페이스**: 여러 도메인의 기능을 일관된 명령어 구조(`al <domain> <action> <resource>`)로 제공하여 학습 비용을 낮춥니다.
- **확장 가능한 아키텍처**: 새로운 도메인(예: finance, weather, news 등)의 명령어를 쉽게 추가할 수 있는 모듈화된 구조를 갖추고 있습니다.
- **Finance (주식/금융)**:
  - **실시간 포트폴리오 조회**: `al finance get stocks` 명령어를 통해 보유 중인 국내/해외 주식의 실시간 평가 금액과 손익을 확인합니다.
  - **잔고 관리**: 보유 현금 및 예탁금 상태를 조회할 수 있습니다.
  - **데이터 정합성**: Yahoo Finance 등의 외부 데이터를 활용하여 API에서 제공하지 않는 최신 시세를 보충하여 정확한 평가액을 계산합니다.

## 📂 프로젝트 구조

```text
al-cli/
├── bin/
│   └── al                  # CLI 진입점 (Node.js 스크립트)
├── src/                    # JavaScript 로직
│   ├── commands/           # 도메인별 명령어 모듈 (finance, ...)
│   └── util/               # 설정 및 인증 유틸리티
├── src_py/                 # Python 로직 (양립 지원)
│   ├── commands/           # 도메인별 Python 명령어 (finance, ...)
│   └── util/config.py      # 환경 변수 관리
├── requirements.txt        # Python 의존성
├── package.json            # Node.js 의존성
└── README.md
```

## 🛠️ 설치 및 실행

1. 의존성 설치:
   ```bash
   npm install
   ```

2. 환경 변수 설정:
   - 프로젝트 루트에 `.env` 파일을 생성하고 API 인증키 등을 입력합니다.

3. 실행 예시:
   ```bash
   npm run start -- finance get stocks
   ```

## 💡 개발 노트

본 도구는 다양한 도메인의 기능을 단일 인터페이스로 통합 제공하기 위해 개발되었으며, `openclaw`와 같은 어시스턴트 에이전트와 연동하여 자동화된 리포트 작성이 가능하도록 설계되었습니다. 금융 기능은 현재 구현된 하나의 도메인이며, 향후 새로운 도메인 명령어를 추가하여 확장할 수 있습니다.
